UX Audit — Where are the friction points?

Based on a full codebase scan. Pick the areas you want to tackle first (multi-select).

A

Navigation & Information Architecture

Sidebar has 10 flat items — no grouping. Settings sub-pages (Team, Webhooks, Security, Data Retention, AI Models) all live at top level alongside core nav. Hard to scan, especially for new users. The active search bar in the topbar does nothing.

B

Chatbot Detail — Tab Order & Labels

Current order: Sources → Settings → Actions → Chat → Customize → Deploy. "Chat" (internal test) is buried as tab 4. "Deploy" is last but should feel like a reward after setup. "Actions" label is vague. Tab order doesn't follow the natural setup flow.

C

Dashboard — Signal vs. Noise

Big resolution rate hero dominates, but there's no "what to do next" CTA. First-time users see an empty dashboard with zeros everywhere. Intelligence highlights exist but feel disconnected. No quick-launch actions from the main screen.

D

Conversations — Discoverability & Speed

No bulk actions, no keyboard shortcuts, no row preview on hover. Clicking a conversation navigates away (no slide-over panel). Status updates require going into the detail view. Filters reset on navigation. Export is buried.

E

First-Time User Experience

Onboarding wizard exists at /onboarding but it's unclear when or if it's triggered. After wizard, users land on dashboard with no context. The new bot wizard (4 steps) is good but the "Done" state has no clear next step. Empty states are minimal — no guided actions.

F

Knowledge Base / Sources Tab

Adding a source opens a modal — fine. But the table only shows status badges with no inline retry for failed docs. Reindexing gives no progress feedback. Sync frequency dropdown is per-row but no bulk-change. "Chunks" count shown but means nothing to most users.

G

Widget Customization — Live Preview UX

Two-column with live preview is good. But the form is long and unsectioned — color, positioning, text, avatar, lead capture, GDPR, custom CSS all in one scroll. No "reset to defaults". Preview doesn't show mobile vs desktop. Save is a single button at the bottom of a long form.

H

Quick Wins — Micro-interactions & Polish

Copy buttons with no feedback, loading states that block the whole page, no toast notifications on save, table rows with no hover action hints, breadcrumbs missing on sub-pages, page titles don't update in browser tab, no keyboard shortcuts anywhere.
